# app/

アプリの起動と配線。ドメインを跨いで決める必要があることだけを置く。

- `router.tsx` — 各ドメインの `routes/` を束ねる。**画面の中身をここに書かない。**
  書くとドメインの境界がこのファイルに滲み、ルータを触るたびに全領域を読むことになる。
- `AppProviders.tsx` / `queryClient.ts` — アプリ全体に配るコンテキスト。
- `sessionExpiry.ts` — 401 を受けたときログイン画面へ戻す配線。遷移先を知っているのは
  ここだけで、`shared/api` は「セッションが切れた」という事実しか知らない。
- `layouts/` — ログイン後の共通の枠。
- `HomePage.tsx` — ログイン直後の入口。まだどのドメインのものでもないためここに居る。
  予約一覧などの実体が生えたら、その画面を index に据えてこのファイルは消す。

**ここが太り始めたら黄色信号。** 「どのドメインに置けばいいか分からないから app に置く」を
続けると、最上位がドメインで切れている意味が無くなる。置き場に迷うものは、たいてい
`shared/` か、まだ名前が付いていないドメインのどちらかになる。
