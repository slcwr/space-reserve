# shared/

どのドメインにも属さない横断的な部品。

- `api/` — `apiClient`（axios インスタンス）と Problem Details の解釈。
  各ドメインの `api/` はここを経由し、`axios` を直接 import しない。
- `components/` — 見た目の据わりを揃えるための素の部品。
- `hooks/` / `lib/` — 領域に依存しない小物。

## 置いてよいものの条件

**2つ以上のドメインが現に使っているもの**に限る。「そのうち共通になりそう」で先に置くと、
実際には片方のドメインの都合を抱えた部品がここに残り、後から剥がすほうが高くつく。
1ドメインでしか使っていないものは、そのドメインの中に置く。

## 禁止

- **各ドメインを import しない。** 依存の向きが逆流する。
- **アプリ固有の判断を持たない。** 「401 ならログイン画面へ」の *遷移先* を知るのは `app/` の
  仕事で、`apiClient` はハンドラを預かるだけにしてある（`api/apiClient.ts`）。
